# Chuyển Sinh, Tôi Trở Thành...

Game pixel sống lại một đời khác, làm trên nền Vạn Kiếp Luân Hồi.

- Next.js + Supabase + Vercel, cùng stack với VKL.
- Database: `supabase/schema.sql` (bảng và hàm tiền tố `cs_`).
- Biến môi trường: xem `.env.example`.
- Nhân vật: bộ hình LPC trong `public/lpc`, ghi nguồn ở `/tac-gia`.
