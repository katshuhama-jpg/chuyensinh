# Đường Tình Rẽ Lối (Love's Altered Lines)

Game pixel hẹn hò: tự tạo nhân vật, sống trọn một đời ở Việt Nam, mỗi lựa chọn rẽ ra một lối tình và một kết cục khác.

- Next.js + Supabase + Vercel (project `lovelines`).
- Database: `supabase/schema.sql` (bảng và hàm tiền tố `cs_`, dùng chung Supabase với bản Chuyển Sinh cũ).
- Biến môi trường: xem `.env.example`.
- Nhân vật: bộ hình LPC trong `public/lpc`, ghi nguồn ở `/tac-gia`.
- Kịch bản: doc "Đường Tình Rẽ Lối - Kịch bản game".
